# Changelog

All notable changes will be documented here. The format follows Keep a Changelog, and releases will use semantic versioning after the first public API exists.

## [Unreleased]

### Added

- Persistent Object Library for successful captures and imported CAD/mesh geometry.
- STEP/STP, GLB/GLTF, OBJ, STL, PLY, OFF, and 3MF ingestion with evidence and warnings.
- Measured scale/mass workflow and downloadable MuJoCo + Gymnasium RL packages.
- Dedicated Capture, Objects, and Environments product workspaces.
- Docker-based Hugging Face Space deployment definition.
- Local video-to-3D API with bounded uploads, capture analysis, SQLite job state, and stable diagnostics.
- Apache-2.0 DA3 Small reconstruction adapter tuned for the target RTX 2050 4 GB laptop.
- Optional COLMAP adapter for classical structure-from-motion and dense reconstruction.
- Responsive KinetiWeave Capture Studio with a real Three.js GLB viewport and evidence inspector.
- Laptop-specific setup, capture guidance, provenance manifests, third-party notices, and tests.
- KinetiWeave project identity and research-first product definition.
- Phase 0 ecosystem, literature, architecture, benchmark, and license reports.
- Open-source governance, roadmap, repository validation, and CI foundation.
